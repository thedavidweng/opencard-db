The open database of credit cards.

OpenCard DB is a community-maintained catalog of credit cards with their fees, rewards and card art. Every record is checked against a schema and reviewed in public, and the data is free to use.

/

Try searching for sapphire, aeroplan, world elite, unionpay or discontinued amex.

    Use the data

    The full catalog is published as static files on jsDelivr and attached to every GitHub release. You can fetch the files directly from the CDN without signing up.

    Pinned release

    Use a tagged URL in production. Tagged files never change and are cached for a year.

    https://cdn.jsdelivr.net/gh/thedavidweng/opencard-db@vX.Y.Z/exports/cards-all.json

    Latest from main

    This URL follows every merged change and is refreshed on each deploy. It works well for prototypes.

    https://cdn.jsdelivr.net/gh/thedavidweng/opencard-db@main/exports/cards-all.json

    Release assets

    Each GitHub release includes the same export files, including the CSV and YAML versions.

    curl -LO https://github.com/thedavidweng/opencard-db/releases/latest/download/cards.csv

    All cards in a single array
    cards-by-id.json
    All cards keyed by id
    index-*.json
    Card ids grouped by country, issuer, network and tier
    cards.csv · cards.yaml
    The catalog as CSV rows and as YAML
    meta.json
    The card count, countries, art grades and build time

    A read-only REST API

    The /v1 API lets you filter, search and look up cards. The official instance is free and runs on a best-effort basis. It asks each client to send a name and allows 30 requests a minute. For production traffic, deploy your own copy on Cloudflare's free plan.

    Each card is one JSON file

    Card files live in data/{country}/. CI validates each file against schema.json, and every file cites the issuer pages its numbers come from.

    Fees
    The annual fee, first-year terms and foreign transaction fee.
    APR
    The purchase APR range and whether it is variable or fixed.
    Rewards
    The rewards currency, the base earn rate, and category multipliers with their caps.
    Provenance
    The official sources for each card, archived in case the pages change.
    Card art
    Card images with a quality grade and SHA-256 hashes.
    {
  "id": "{country}-{slug}",
  "name": string,
  "issuer_id": string,
  "network": "visa" | "mastercard" | "amex" | …,
  "network_tier": "world_elite" | "infinite" | …,

  "sources": [ … ],

}

    Add a card with a pull request

    CI validates the schema, checks your sources and labels the PR. A maintainer reviews the facts before it merges.

    1. Copy the template

      Copy templates/card.template.json into data/{country}/.

    2. Fill in the fields

      Cite the issuer's own page for every number you enter.

    3. Validate

      npm run validate runs the same checks as CI.

    4. Open a pull request

      If you would rather not edit JSON, you can file a card request instead.

    Add card art from Apple Pay

    If your cards are in Apple Pay on a Mac, opencard-export finds the ones that are missing art in the database and prepares a pull request with the images. It runs on your machine and does not upload anything.

    npx opencard-export
