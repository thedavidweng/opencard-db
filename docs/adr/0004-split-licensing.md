# Split licensing: MIT code, CC BY 4.0 data, bank-owned images

Code in this repository (Worker, scripts, workflows, tooling) is licensed under MIT. Structured Card data under `data/` is licensed under Creative Commons Attribution 4.0 (CC BY 4.0); redistributors must give attribution. Card face images are not relicensed: they remain the copyright of the issuing bank or network. Prefer official image URLs; optional local mirrors under `images/` are identification-only and must be removed on request.

**Status:** accepted

**Considered options:** entire repo MIT; entire repo CC BY. Rejected because data redistributors need a clear attribution norm, and code contributors expect MIT; neither license applies cleanly to third-party bank artwork.
